### Start with clone this project 
### Then install npm by : 
```bash
npm i
```
# If error with lucide install it :
```bash
npm install lucide
```
### First time to run dev server : 
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
